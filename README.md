# rinakzhigitov.ru

Личный сайт Рината Акжигитова — продакт-менеджера. Astro, статика, хостинг reg.ru.

## Как редактировать

| Что поменять | Где |
|---|---|
| Тексты главной: заголовок, факты, «Обо мне», компетенции, компании, образование, «Вне работы» | `src/data/site.ts` |
| Кейсы (один файл — один проект) | `src/content/projects/*.md`, схема полей — `src/content.config.ts` |
| Статьи (один файл — одна статья) | `src/content/articles/*.md` — см. шаблон ниже. Раздел и пункт меню появляются, когда есть хотя бы одна статья |
| Цвета, шрифты, размеры | `src/styles/global.css` |
| Фото | `src/assets/photo/` |
| Логотипы компаний | `public/logos/` + список в `src/data/site.ts` |
| Резюме | `public/resume.pdf` |

Папка `materials/` — исходники кейсов и фото. В репозиторий не попадает (`.gitignore`).

## Команды

```bash
npm install        # один раз
npm run dev        # локально: http://localhost:4321
npm run build      # сборка в dist/
```

Публикация — автоматически при пуше в `main`: GitHub Actions собирает сайт и заливает его по FTP на хостинг reg.ru (секреты FTP_HOST, FTP_USER, FTP_PASSWORD в настройках репозитория).

## Как добавить статью

Создайте файл `src/content/articles/<slug>.md` (slug латиницей, он станет адресом `/articles/<slug>/`):

```md
---
title: 'Заголовок статьи'
description: 'Одно-два предложения: о чём статья. Показывается в списке и в поисковиках.'
order: 1                          # порядок карточек: меньше — выше
tags: ['CX', 'метрики']          # необязательно
# cover: ./my-cover.jpg          # необязательно: картинка рядом с файлом
# external: 'https://…'          # если статья опубликована на другой площадке — карточка будет вести туда
draft: false                     # true — не публиковать
---

Текст статьи в Markdown: заголовки `##`, списки, **жирный**, ссылки, цитаты `>`.
```

Закоммитьте и запушьте в `main` — через минуту статья на сайте.
